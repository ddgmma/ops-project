## 架构

```
                        Internet
                            │
        ┌───────────────────┴────────────────────┐
        │                                        │
  blog.ddgmm.top                          monitor.ddgmm.top
        │                                        │
        └──────────────┬─────────────────────────┘
                       ▼
              ┌─────────────────┐
              │  nginx  80/443  │  ← 宿主机唯二对外端口
              │  (反向代理 +    │
              │   HTTPS 终止)   │
              └────┬───────┬────┘
                   │       │
        fastcgi    │       │  proxy_pass
        (9000)     ▼       ▼
      ┌──────────────────┐  ┌─────────────────┐
      │ wordpress:6-fpm  │  │ grafana:3000    │
      │  /var/www/html   │  └────────▲────────┘
      └────────┬─────────┘           │ 读数据
               │ 共享卷 wp_data      │
               ▼                     │
      ┌──────────────────┐  ┌────────┴────────┐
      │ mysql:8.0        │  │ prometheus:9090 │ ← 只监听 127.0.0.1
      │ (db_data 卷)     │  └────────▲────────┘
      └──────────────────┘           │ 每 15 秒抓取
                       ┌─────────────┼─────────────┬──────────────┐
                       │             │             │              │
               node-exporter    cAdvisor    blackbox-exporter  alertmanager
                (主机指标)      (容器指标)   (站点可用性拨测)    (发邮件告警)
```

## 技术栈与版本矩阵

| 组件           | 镜像 / 软件               | 固定版本                                                     | 作用                                                         |
| -------------- | ------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 操作系统       | Ubuntu                    | 24.04 LTS                                                    | 服务器系统                                                   |
| 容器引擎       | Docker CE + Compose v2    | Docker version 29.8.1, build 4a63305<br />Docker Compose version v5.5.1 | 跑所有服务                                                   |
| Web / 反向代理 | `nginx:1.30.5`            | nginx/1.30.5                                                 | 统一入口、HTTPS 终止、静态资源                               |
| 应用           | `wordpress:6-fpm`         | PHP 8.3.31 (cli)                                             | 模拟业务系统                                                 |
| 数据库         | `mysql:8.0`               | mysql  Ver 8.0.46 for Linux on x86_64 (MySQL Community Server - GPL) | 业务数据                                                     |
| 指标采集       | `prom/node-exporter`      | v1.10.2                                                      | 主机 CPU/内存/磁盘/网络                                      |
| 容器指标       | `ghcr.io/google/cadvisor` | v0.60.5                                                      | 每个容器的资源使用（版本更新频繁，拉不到就去 Docker Hub 查当前版本） |
| 站点拨测       | `prom/blackbox-exporter`  | v0.26.0                                                      | 模拟"用户能不能打开网站"                                     |
| 时序数据库     | `prom/prometheus`         | v3.5.0（LTS）                                                | 存储指标、算告警规则                                         |
| 告警分发       | `prom/alertmanager`       | v0.28.0                                                      | 把告警发到你的邮箱                                           |
| 可视化         | `grafana/grafana`         | 12.3.1                                                       | 监控面板                                                     |
| 证书           | certbot + Let's Encrypt   | apt 最新                                                     | 免费 HTTPS 自动续期                                          |
| 备份           | bash + cron + 腾讯云 COS  | —                                                            | 每日自动备份                                                 |
| 流水线         | GitHub Actions            | —                                                            | 自动部署与回滚                                               |
